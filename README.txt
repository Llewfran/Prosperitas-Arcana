Prosperitas Arcana Table Aid - install on the Master's iPad

1. Upload every file in this folder to any static HTTPS host (GitHub Pages, Netlify Drop, Cloudflare Pages).
   Keep the files together in one folder.
2. On the iPad open the address in Safari.
3. Tap Share, then Add to Home Screen, then Add.
4. Open it from the home screen once while online. After that it runs offline, full screen.

Notes
- Game data is saved on that device only. Use Master > Backup before clearing Safari data.
- To release an update, change VERSION in sw.js, re-upload, and reopen the app online twice.

Own-device players
- Everyone (Master and players) opens the same hosted address; players can also Add to Home Screen.
- Master: on the table screen choose "Use own device" for a seat, set the Demand Market and stock, then "Send seat link".
- Player: opens the link (or pastes it under "Join as a player"), builds and locks the order, then taps "Send to Master".
- Master: pastes the order code into that seat and taps "Import order". The Master's own rules check re-runs before it locks.
- Each Year the Master sends a fresh seat link, because stock and market change.
